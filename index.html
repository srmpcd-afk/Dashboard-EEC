ภาพรวมกรณีลักลอบทิ้งของเสียและโรงงานรีไซเคิลในพื้นที่ EEC

ติดตามตำแหน่ง สถานะคดี และแนวโน้มของกรณีที่รายงานเข้ามา อัปเดตอัตโนมัติเมื่อเชื่อมกับ Google Sheet หรืออัปโหลดไฟล์ข้อมูลใหม่

แหล่งข้อมูล

อัปโหลดไฟล์ หรือเชื่อมต่อ Google Sheet เพื่อดึงข้อมูลอัตโนมัติ

ยังไม่มีข้อมูล กรุณาอัปโหลดไฟล์ .csv, .xlsx หรือ .xls เพื่อเริ่มใช้งาน
หรือ
วิธีตั้งค่า Apps Script (ทำครั้งเดียว)
  1. เปิดชีตของคุณ → เมนู Extensions (ส่วนขยาย) → Apps Script
  2. ลบโค้ดเดิมในไฟล์ Code.gs ออกทั้งหมด แล้ววางโค้ดที่ให้ไว้ด้านล่างแทน
  3. กด Deploy (ปรับใช้) → New deployment (การปรับใช้ใหม่)
  4. เลือกประเภท (ไอคอนเฟือง) เป็น Web app
  5. ตั้งค่า Execute as: Me (สำคัญ — สคริปต์จะอ่านชีตแทนคุณ ชีตจึงไม่ต้องเปิดสาธารณะ)
  6. Who has access: เลือก "Anyone" (คนที่มีลิงก์ Web App เท่านั้นที่ดึงข้อมูลได้ ตัวชีตจริงยังปิดอยู่เหมือนเดิม) หรือ "Anyone within [องค์กร]" ถ้าใช้ Google Workspace และอยากจำกัดเฉพาะคนในองค์กร
  7. กด Deploy → หากมีหน้าต่างขออนุญาต (Authorize) ให้เลือกบัญชีเจ้าของชีตแล้วกดอนุญาต
  8. คัดลอก Web app URL (ลงท้ายด้วย /exec) มาวางในช่องด้านบน
  9. ⚠️ ถ้าแก้โค้ดสคริปต์ทีหลัง ต้องกด Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → เวอร์ชันใหม่ → Deploy ใหม่ทุกครั้ง ไม่งั้นระบบจะยังใช้โค้ดเวอร์ชันเก่าอยู่

โค้ดสำหรับวางใน Code.gs:

function doGet(e) {
  var tab = e.parameter.sheet;
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = tab ? ss.getSheetByName(tab) : ss.getSheets()[0];
  if (!sheet) {
    return ContentService.createTextOutput(JSON.stringify({error: 'ไม่พบชีต/แท็บ: ' + tab}))
      .setMimeType(ContentService.MimeType.JSON);
  }
  var data = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}
ต้องตั้งค่าอะไรก่อนเชื่อมต่อ?
  1. เปิดชีต → กด Share → ตั้ง General access เป็น "Anyone with the link" / "ทุกคนที่มีลิงก์" สิทธิ์ Viewer
  2. วางลิงก์ชีตในช่องด้านบน (ถ้ามีหลายแท็บและต้องการแท็บที่ไม่ใช่แท็บแรก ให้ใส่ชื่อแท็บด้วย)
  3. โครงสร้างคอลัมน์ในชีตต้องตรงกับที่แดชบอร์ดนี้รองรับ (เหมือนไฟล์ที่อัปโหลดได้ตามปกติ)
  4. กด "เชื่อมต่อ" — ระบบจะดึงข้อมูลทันที และรีเฟรชซ้ำตามความถี่ที่เลือก (ยังต้องเปิดหน้านี้ทิ้งไว้ในเบราว์เซอร์ระหว่างรอข้อมูลอัตโนมัติ)
